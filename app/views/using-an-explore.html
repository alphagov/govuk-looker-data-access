Examples using a Looker Explore

Metric from an Explore

This is using the run_inline_query function to query a measure from the govuk Explore. 


        const query = await sdk.run_inline_query({
          result_format: 'json_detail',
          body: {
            model: 'govuk',
            view: 'govuk',
            fields: ['govuk.sessions'],
            filters: { 'govuk.event_date': looker_date_filter },
            total: false,
          },
        });

Time-series from an Explore

Getting a time-series is straight-forward if you include a date dimension. The result is still an array as for a single-field metric but will have multiple elements. 


        const query = await sdk.run_inline_query({
          result_format: 'json_detail',
          body: {
            model: 'govuk',
            view: 'govuk',
            fields: [
              'govuk.sessions',
              'govuk.event_date' <-- same query as for a single metric but with added date dimension
            ],
            filters: { 'govuk.event_date': looker_date_filter },
            total: false,
          },
        });

Allowing user-input to filter an Explore

You can filter on as many dimensions as you need to. You would just need to hook up the plumbing to get, sanitise and pass through user input. 


        const query = await sdk.run_inline_query({
          result_format: 'json_detail',
          body: {
            model: 'govuk',
            view: 'polling_question_response_selections',
            fields: ['polling_survey_waves.start_quarter', 'polling_survey_responses.count_survey_responses'],
            sort: ['polling_survey_waves.start_quarter'],
            filters: {'polling_survey_responses.age_group': filterAgeValueFromDropdown}, <-- Just need to pass the correct values
            total: false
          }
        });
