Embedding Looks and Dashboards with the Embed SDK

If you are interested in showing visualisations built in Looker rather than just pulling metrics then embedding may be more appropriate. You can present Looks and Dashboards to the user and these can includes filters to allow interactivity. However, most of the configuration for what is allowable happens in the Looker instance (Admin -> Platform -> Embed). The embedding application is relatively limited in how it presents that information.

Public Embedding

If you have something that is genuinely intended to be accessible by anyone on the internet then embedding is very simple. There is an administrative setting in Looker that will control whether content is allowed to be made public (Admin -> General -> Settings -> Data Policy -> "Public URLs"). If so, an individual look/dashboard can then have "Public Access" enabled. A URL will be generated which can be embedded within external sites or applications.

Private Embedding

If your use-case is to make content available to users with a Looker account then you can embed content within a iframe. This will require the user to be signed in to Looker. Both Private and Signed Embedding require admin settings in the Looker instance to explicitly allow embedding a specific domain. This may be configured in Admin -> Platform -> Embed -> "Embedded Domain Allowlist".
